# Faded Pearl 1.8.0-beta.3

This is the first public beta of Faded Pearl.

## Highlights

- Find a wounded Fade naturally in underground caves and discover how to heal him.
- Build trust and unlock commands, protection, carrying, curiosity and world reactions.
- Use the Enderman Journal, Resonating Anchor and permanent Escape Pearl upgrade.
- Maintain separate companion relationships for different players.
- Continue a tested older world through the recovery and migration safeguards.

## Verified scope

- clean build and 331 automated tests;
- fresh singleplayer encounter, healing, Save/Quit, recovery, commands, Home and Anchor recall;
- behavioral migration from a disposable 1.4.1 test world;
- corrected animated finger attachment in representative runtime clips.

## Beta limitations

- Multiplayer is experimental. The current build has not received a complete dedicated-server
  regression covering restarts, disconnects, simultaneous recovery and dimension travel.
- Comparative performance profiling for 0/1/10/25 active Fades remains open.
- The final compatibility matrix for larger modpacks remains open.

Back up important worlds and install the exact same Faded Pearl JAR on the server and every
client. See the
[installation instructions](https://github.com/KrzakZCzarnobyla/Faded-Pearl-Public/blob/main/docs/INSTALLATION.md)
and [known limitations](https://github.com/KrzakZCzarnobyla/Faded-Pearl-Public/blob/main/docs/KNOWN_LIMITATIONS.md)
before updating an existing world.
